# Auto Decor (Geode mod for Geometry Dash 2.2081)

Adds a **Decor** button to the level editor. It decorates the level and sets up colors automatically.

## Getting the .geode file without installing anything
1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the **Actions** tab and wait for "Build Geode Mod" to finish (about 5-10 minutes).
3. Open the finished run and download **Build Output**. Inside is `yourname.auto-decor.geode`.
4. Put the .geode file into the `geode/mods` folder of your Geometry Dash install and restart the game.

## Building locally
Install the Geode SDK and CLI, then run `geode build` in this folder.

Before building, replace `yourname` in `mod.json` with your own name.
